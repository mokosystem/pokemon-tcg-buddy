# pokemon-tcg-buddy

ポケモンカードのデッキ構築とデッキ診断を支援する AI エージェントを作るプロジェクト。

## 目的

既存のデッキ診断サービスの出力には、カードの事実(にげるエネルギーやタイプ)に反する解説、デッキに入っていないカードを前提にした解説、レギュレーションで使えないカードへの言及が見られた。使えないカードを初心者に勧めると、買っても対戦で使えないという金銭的な実害につながる。

この種の誤りは、ポケモンカードのルール、スタンダードレギュレーションのカードプール、現行レギュレーションの 3 点を確認しないまま文章を生成すると起きる。このプロジェクトでは、この 3 点を一次情報(公式サイト)で確認してから助言するエージェントを作る。

## 対象ユーザー

初心者から中級者を中心とする。一部で上級者向けの機能も視野に入れる。

## 提供形態

Claude Code や Cursor などのコーディングエージェント上で動くエージェントスキルとして提供する。このリポジトリを開いたエージェントが、そのままデッキ構築とデッキ診断の相談相手になる形を最初のゴールとする。一般ユーザー向けの UI は後から検討する。

## 対象レギュレーション

スタンダードレギュレーションのみ。エクストラレギュレーションと殿堂レギュレーションは扱わない。日本語のカードを対象とする。

## デッキ構築のアウトプット

デッキ構築の最終アウトプットは、公式デッキ構築ツールに登録されたデッキ(デッキコード)とする。公式大会への参加にはこのツールへのデッキ登録が必要なため、ここに登録できて初めて完成とみなす。

https://www.pokemon-card.com/deck/

## 情報源の方針

1. カードの実在、カードテキスト、スタンダードで使えるかどうかは、ポケモンカード公式のカード検索で確認する。ここに載っていないカードはスタンダードでは使えない。
   https://www.pokemon-card.com/card-search/
2. レギュレーションの現況は公式のレギュレーションページで確認する。使用できるレギュレーションマークは切り替わっていくため、固定値をドキュメントに書き散らさず、都度このページを参照する。
   https://www.pokemon-card.com/rules/regulation/
3. 基本ルールは公式のあそびかたページで確認する。
   https://www.pokemon-card.com/howtoplay/
4. カードの効果や数値をモデルの記憶だけで断定しない。不確かなことは不確かだと明示する。
5. 公式サイトは無断転載を禁じているため、カード画像やページの内容をリポジトリに転載保存しない。参照手順とリンクを整備する。
