# スタンダードデッキ構築ガイド

スタンダードレギュレーションのデッキを、公式サイトを一次情報として新規に構築する。最終アウトプットは、公式デッキ構築ツールに登録されたデッキ(デッキコード)と、採用した全カードの確認記録。

作業前に `docs/pokemon-tcg/site-usage-notes.md` を読む。

## このスキルで扱わないもの

- デッキ診断と、既存デッキの改良
- マイデッキ登録(プロジェクトの対象外。エージェントが担うのはデッキコードの発行まで。`docs/pokemon-tcg/deck-tool.md`)
- スタンダード以外のレギュレーション

## 構築フロー

1. **要望を聞く**。使いたいカード、デッキの方向性に加え、レアリティ・印刷の希望(手持ちのカードと同じ印刷で登録したい等)があるかも確かめる
2. **候補カードを確認する**。`docs/pokemon-tcg/card-lookup.md` に従い、実在・スタンダードで使えるか・カードテキストの 3 点を確認する
3. **構築ルールを守って 60 枚を決める**。下記「デッキ構築ルール」に反しない範囲で、「デッキ構成の枚数の目安」を出発点に初案を組み、要望に合わせて調整する
4. **公式デッキ構築ツールで構築し、レギュレーションチェックを実行する**。`docs/pokemon-tcg/deck-tool.md` の手順 2 に従う。印刷の指定があるカードは、その印刷のカード ID で登録する(同手順 5)
5. **デッキ登録し、デッキコードと確認記録を提示する**

## デッキ構築ルール

守らないとレギュレーションチェックを通らない決まり。確認元は `docs/pokemon-tcg/basic-rules.md`「デッキの規定」と、その出典のあそびかたページ(https://www.pokemon-card.com/howtoplay/ 。2026-08-23 に再確認)。

- デッキはちょうど 60 枚
- 同じ名前のカードは 4 枚まで。ただし基本エネルギーは何枚でも入れられる
- たねポケモンを 1 枚以上入れる
- 進化ポケモンを使うには、進化前のポケモンもデッキに入れる
- **ACE SPEC のカードはデッキ全体で 1 枚まで。種類が違っても合計 1 枚**(公式 Q&A で確認。検索結果 URL: https://www.pokemon-card.com/rules/faq/search.php?freeword=ACE%20SPEC%20%E3%83%87%E3%83%83%E3%82%AD&regulation_faq_main_item1=all 、該当 Q&A の要旨: ACE SPEC のゴールドポーションとパソコン通信を 1 枚ずつ入れられるかという質問への回答が「できない」。2026-08-23 確認。ACE SPEC のカード詳細ページの「ACE SPECのカードは、デッキに1枚しか入れられない。」の記載でも確認)
- 同じ名前のカードは、印刷(レアリティ・収録)が違っても同じ名前として数える。印刷違いの扱いは `docs/pokemon-tcg/deck-tool.md` の手順 5

## デッキ構成の枚数の目安

60 枚の初案を組むときは、ポケモン 15〜20 枚、トレーナーズ 25〜30 枚、エネルギー 10〜12 枚を出発点にする。

トレーナーズの内訳は、枚数合わせではなく次の役割が欠けていないかで考える。枚数は大まかな目安。

| 役割 | 意味 | 枚数の目安 | 例(2026-08-23 に 3 点確認済み。カッコ内は確認した印刷のカード ID) |
| --- | --- | --- | --- |
| ボール系 | 山札からポケモンを探し出すグッズ | 合計 12 枚程度 | ハイパーボール(49367)、なかよしポフィン(49364)、ポケパッド(50463) |
| ドローサポート | 山札からカードを大量に引けるサポート | 6〜7 枚 | リーリエの決心(50468) |
| 裏呼び | 相手のベンチポケモンをバトル場に呼び出すカード | 4 枚程度 | ボスの指令(50467)、プライムキャッチャー(49372。ACE SPEC) |
| スタジアム | — | 1〜3 枚 | 活力の森(50076) |
| 手札干渉 | 相手の手札を山札に戻させるなど、相手の手札に干渉するカード | デッキ次第で採用 | スペシャルレッドカード(50474)、アンフェアスタンプ(49349。ACE SPEC) |

目安を使うときの注意。

- **この目安は構築ルールではない。** 外れてもレギュレーション違反にはならず、目安に合わせること自体を目的にしない
- 要望やデッキの戦略に応じて外れてよい。大会で結果を残しているデッキにも、この比率から外れるものは多い。特にエネルギーは目安より少なくする例が多い
- 目安から大きく外れる初案を提案するときは、外す理由をユーザーに説明する
- **例示カードは確認日時点の例。** レギュレーションの変化で使えなくなるため、提案に使う前に必ず 3 点確認をやり直す

根拠: 開発責任者の判断(2026-08-23。ボール系の枚数は 2026-09-06 に 12 枚程度へ改めた)。大会入賞デッキの多くもおおむねこの構成に収まるという分析による。参考: 【公式】ポケモンカードチャンネルの動画「【ポケカ初心者】デッキはどうやって作る！？最初の一歩をこの動画で学ぼう！【ポケモンカード】」 https://www.youtube.com/watch?v=frhctQfqoWc (2026-08-23 確認)、note 記事「ポケカの構築って、各パーツの基本枚数はどんなものだろうか？(雑記)」(hatanaka_pokeca、2024-09-18) https://note.com/hatanaka_pokeca/n/n11c35c9c0d6a (2026-08-23 確認)

## 助言の原則

- カードの効果、数値、使用可否を記憶で断定しない。カード詳細ページを開いて確認してから書く
- 効果や数値への言及は、確認したページの内容を自分の言葉で書く。本文を引き写さない(`docs/pokemon-tcg/site-usage-notes.md`)
- 不確かな点は不確かと明示する
- 確認した事実には、詳細ページの URL と確認日を添える

## 確認記録の書き方

デッキコードと一緒に、採用した全カードの確認記録を次の表で提示する。

| カード名 | 枚数 | カード ID | 詳細ページ URL | 確認日 |
| --- | --- | --- | --- | --- |

- 行があること自体が、そのカードについて `docs/pokemon-tcg/card-lookup.md` の 3 点確認を終えたことを意味する
- カード ID は、実際に登録した印刷の ID を書く(カード ID が印刷の特定になる)
- 確認記録は会話の成果物としてユーザーに提示する。リポジトリにファイルとして残さない
