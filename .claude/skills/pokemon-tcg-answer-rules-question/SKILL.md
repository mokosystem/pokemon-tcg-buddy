# ルール質問への回答ガイド

ルールや裁定の質問に、公式サイトを一次情報として答える。記憶にある答えと一致していそうでも、確認してから書く。

作業前に `docs/pokemon-tcg/site-usage-notes.md` を読む。

## 回答フロー

1. **質問に登場するカードの事実を確認する**。`docs/pokemon-tcg/card-lookup.md` に従い、カード詳細ページでタイプ、進化(たね・1 進化・2 進化の別と進化の系統)、テキストを読む。質問の前提がカードの事実と食い違っていることがある(思い違いや別カードとの混同)ため、この手順を飛ばさない
2. **公式 Q&A を検索する**。`docs/pokemon-tcg/faq-lookup.md` に従う。一般ルールの質問はルールの語彙に言い換えて検索し、到達できなければ語を変えて引き直す
3. **Q&A に無ければ、基本ルール文書とあそびかたページを当たる**。`docs/pokemon-tcg/basic-rules.md` に該当があれば、その項目の出典になっているあそびかたページの記述を確認する
4. **出典を添えて回答する**。書き方は次節

## 回答の書き方

- 結論を先に書く
- 根拠は自分の言葉で書く。Q&A やページ本文を引き写さない(`docs/pokemon-tcg/site-usage-notes.md`)
- 出典として、回答の確認に使ったものを添える
  - 確認したカード詳細ページの URL
  - Q&A で確認した場合、検索結果 URL と該当した Q&A の質問文の要旨(`docs/pokemon-tcg/faq-lookup.md` の「出典の書き方」)
  - あそびかたページなどのルール文書で確認した場合、そのページの URL と該当箇所の要旨
  - 確認日

## 公式資料に該当が見つからないとき

- 公式資料に該当が見つからなかったと明示する。使った検索語と参照先も書くと、読み手が追試できる
- そのうえで推測を述べる場合は、推測であることを明示し、確認済みの事実と区別する
- 見つからなかったことを根拠に、質問者の解釈を肯定も否定もしない

## 禁止する回答

- 記憶だけでカードの効果、数値、使用可否、裁定を断定する
- 確認していない URL を出典として添える。出典に書いてよいのは、この回答のために実際に開いて確認したページだけ
