# 公式 Q&A の検索手順

ルールや裁定の疑問について、公式 Q&A 検索(https://www.pokemon-card.com/rules/faq/)で確認する手順を定める。

作業前に[公式サイト利用上の注意](site-usage-notes.md)を読むこと。

最終確認日: 2026-08-22。URL の形式やページ構造は公式サイトの実装から確認した観測結果であり、公式が保証する仕様ではない。動作しなくなっていたら、Q&A 検索ページを画面から操作して現在の挙動を確認し、この手順書を直す。

## 1. Q&A 検索の URL

Q&A 詳細検索ページ(https://www.pokemon-card.com/rules/faq/)の検索フォームは GET パラメータで実行できる(2026-08-22 にフォーム実装と動作を確認)。

```
https://www.pokemon-card.com/rules/faq/search.php?freeword={検索語}&regulation_faq_main_item1={レギュレーション}
```

| パラメータ | 値 | 意味 |
| --- | --- | --- |
| freeword | 検索語 | 複数語はスペース区切り |
| regulation_faq_main_item1 | XY / BW / DP / all | 値による絞り込みの挙動の違いは未確認。取りこぼしを避けるため all を使う |

検索語の一致のしかたについて、確認できているのは次の範囲。

- 検索語が質問文に一致した例を確認済み。回答文にも一致するかは未確認
- 複数語の区切りは、全角スペースでも半角スペースでも同じ結果になった(「違うタイプ　進化」でどちらも 2 件)。複数語にすると件数が大きく絞られるため各語での絞り込みとみられるが、一致箇所の仕様は未確認
- 漢字の検索語がひらがな表記にも一致した観測例がある(「違うタイプ　進化」で検索したとき、検索語「進化」に対する強調がワザ名「しんかのきざし」の「しんか」に付いた)。表記ゆれはある程度吸収されるようだが、保証はない

検索ページ自体について。

- カード名やカードに記載されているテキストで検索するようにとの案内があり、ルールの解説だけでなく一部カードの特性やワザの解説も掲載されている旨が書かれている
- 「商品ごとに探す」の一覧もある。各リンクは `search.php?sc_group_id={商品ID}` の形式(一部は sc_series_ids も付く)。リンク先の内容は未確認のため、商品単位で探すときは URL を組み立てず、ページ上のリンクをたどる

## 2. 検索語の選び方(重要)

一般ルールの質問には、カード名ではなくルールの語彙を使う。

- カード名で検索すると、そのカードの特性やワザの個別裁定に埋もれる。「ブルンゲル」は 34 件で、1 ページ目はすべて個別カードの裁定だった(2026-08-22 確認)
- 1 語だけの広い語も埋もれる。「進化」は 1400 件だった(2026-08-22 確認)
- 質問をルールの語彙に言い換え、複数語で絞る。「タイプの違うポケモンから進化できるか」という質問なら「違うタイプ　進化」で 2 件になり、先頭に該当の Q&A(タイプのちがうポケモンでも進化させることはできるか)が出る(2026-08-22 確認)
- 目的の Q&A に到達できなければ、別の語に言い換えて引き直す。1 回で当てようとしない

特定のカードの特性やワザの裁定を探すときは逆で、カード名やワザ名で検索する。

## 3. 検索結果ページの読み方

- 件数は「検索結果 N件」と表示される。1 ページに 10 件で、`page={ページ番号}` パラメータで送る
- 各項目は `li.FAQResultList_item` で、質問が `.QuestionArea` 内、回答が `.AnswerArea` 内にある
- 検索語は `<em class="search-word">` で強調され、テキストがタグで分断される。HTML の文字列一致で質問文を探すと見つからないことがあるため、表示テキストを読む
- 項目には「関連カード」として、カード詳細ページ(`/card-search/details.php/card/{カード ID}/regu/all`)へのリンクが付くことがある
- 0 件のときは「検索結果 0件」と、条件にあてはまる Q&A が無かった旨のメッセージが表示される(2026-08-22 確認)

## 4. 出典の書き方

個別の Q&A 項目への固定リンクは無い(2026-08-22 確認。結果一覧の項目に id、アンカー、個別ページへのリンクのいずれも無い)。出典は次の 3 点で残す。

1. 検索結果 URL(freeword 付き)
2. 該当した Q&A の質問文の要旨(自分の言葉で書く。本文を引き写さない)
3. 確認日

検索結果は Q&A の追加や改廃で変わりうるため、URL だけでは後から該当項目をたどれない。質問文の要旨を必ず添える。

## 5. Q&A に見つからないとき

1. あそびかたページ(https://www.pokemon-card.com/howtoplay/)を確認する。対戦の骨格のルールは[基本ルール](basic-rules.md)に出典付きでまとめてあるので、先にそちらを引いてから出典のページで確かめてもよい
2. それでも見つからなければ、公式資料に該当なしとして扱う。扱い方は `pokemon-tcg-answer-rules-question` スキルに従う

Q&A 検索ページの下部には、調べても答えが見つからないときのお問い合わせ導線がある。人間のプレイヤーに次の手を案内するときは、これを紹介できる。
