# カード情報の確認手順

任意のカード名について、次の 3 点を公式サイトで確認する手順を定める。

1. カードが実在するか
2. スタンダードレギュレーションで使えるか
3. カードテキスト(特性、ワザ、弱点・抵抗力・にげる など)

作業前に[公式サイト利用上の注意](site-usage-notes.md)を読むこと。

最終確認日: 2026-08-22。URL の形式やページ構造は公式サイトの実装から確認した観測結果であり、公式が保証する仕様ではない。動作しなくなっていたら、カード検索ページを画面から操作して現在の挙動を確認し、この手順書を直す。

## 1. カード検索で探す

カード検索(https://www.pokemon-card.com/card-search/)は GET パラメータで条件を指定できる。検索フォームの送信先とパラメータ名は次の通り(2026-08-22 にフォーム実装と動作を確認)。

```
https://www.pokemon-card.com/card-search/index.php?keyword={検索語}&se_ta={種類}&regulation_sidebar_form={レギュレーション}&sm_and_keyword=true
```

| パラメータ | 値 | 意味 |
| --- | --- | --- |
| keyword | 検索語 | カード名とカードテキストの両方に部分一致する |
| se_ta | 空 / pokemon / trainer / energy | カードの種類。空はすべて |
| regulation_sidebar_form | XY / BW / DP / all | XY=スタンダード、BW=エクストラ、DP=殿堂、all=すべて |
| sm_and_keyword | true | フォームが常に付与する。省略時の挙動は未確認 |

- カード検索ページを開くと `regulation_sidebar_form=XY` が付いた URL に遷移する。スタンダード絞り込みが初期状態
- keyword は部分一致で、名前の一部でもヒットする(「シロナのガブリアス」で「シロナのガブリアスex」がヒットすることを確認)
- keyword はカードテキストにもマッチするため、カード名の確認だけが目的なら結果にテキスト一致が混ざる点に注意する(「特性」で検索するとワザの説明文に「特性」を含むカードもヒットすることを確認)

## 2. 検索結果を読む

- ヒットしない場合は「0 件」と表示される
- **件数表示は当てにしない。** 読み込みの途中に別の数字が出ることがあるうえ、表示が落ち着いたあとも実際に並ぶカードの枚数と一致しないことがある(「ボスの指令」で表示 12 件・実際 39 枚を確認)。ヒットの有無と枚数は、結果一覧に並んだカードで判断する
- **結果一覧は 1 ページに約 39 枚で頭打ちになる。** 続きは `page={ページ番号}` パラメータで表示できる(「ポケモンいれかえ」で 2 ページ目に別の印刷が並ぶことを 2026-08-23 に確認)。1 ページ目に無いことをもって不在と判断しない
- 結果一覧のカードは `<a id="card-show-idN"><img alt="カード名"></a>` の形式。**カード名は img の alt 属性**にある
- カードのリンクには href が無く、クリックすると詳細ページが別ウィンドウで開く実装になっている。エージェントは後述の URL を組み立てて開くほうが確実
- **カード ID は画像パスから取得する**。パスの形式は次の通りで、ファイル名先頭の数字がカード ID(例: 047339)

```
/assets/images/card_images/large/{エキスパンションマーク}/{カード ID}_P_{ローマ字名}.jpg
```

- 画像は遅延読み込みされる。読み込み前は src がプレースホルダー(1x1 の GIF)のため、**本来のパスは img の data-src 属性から読む**
- ファイル名の種別記号はポケモンが `_P_`、トレーナーズが `_T_`(観測例より)

## 3. カード詳細ページを開く

カード ID を使って詳細ページを開く。

```
https://www.pokemon-card.com/card-search/details.php/card/{カード ID}/regu/XY
```

ページタイトルがカード名になる(例: 「シロナのガブリアスex | ポケモンカードゲーム公式ホームページ」)。

## 4. カード詳細ページを読む

### ポケモンのカード

上から順に次が表示される(シロナのガブリアスex、ノクタス、ヤバソチャで確認)。

- カード名、コレクションナンバー、イラストレーター名
- 進化マーク(「たね」「1進化」「2進化」)、HP、タイプ(アイコン)
- 特性(持っている場合): 見出し「特性」の下に特性名と説明文
- ワザ: 必要なエネルギー(アイコン)+ワザ名+ダメージ(「100」「10＋」などの表記)、説明文
- 特別なルール(持っている場合): 「ポケモンexがきぜつしたとき、相手はサイドを2枚とる。」など
- 弱点・抵抗力・にげる(表形式)
- 進化の系統、収録商品名

### トレーナーズのカード

トレーナーズの分類(「グッズ」など)が見出しとして表示され、カードテキストに続いて分類の共通ルール(「グッズは、自分の番に何枚でも使える。」など)も表示される(ハイパーボールで確認)。

### アイコンの読み方(重要)

タイプ、ワザに必要なエネルギー、弱点のタイプ、にげるエネルギーは**画像やテキストではなく `<span class="icon-{英語タイプ名} icon">` という空の span** で表現される。確認した対応は icon-grass=草、icon-fighting=闘、icon-electric=雷、icon-none=無色。

- **ページの表示テキストだけを抽出するとアイコンの情報は消える。** 必要なエネルギーやタイプを読むときは HTML の class 名を確認する
- にげるエネルギーは、にげる欄(`td.escape`)内のアイコンの個数。**にげるエネルギー 0 のカードは欄が空になる**(シロナのガブリアスex で確認)。エネルギーをトラッシュせずにげられるという意味であり、欄が空でも読み取りエラーではない
- 該当が無い欄は「--」と表示される(抵抗力で確認)

## 5. スタンダードで使えるかを判定する

1. `regulation_sidebar_form=XY` で検索し、**確認したい名前と一致するカードがヒットする** → **スタンダードで使える**(実在の確認を兼ねる)。過去のシリーズのカードで現在も使えるもの(例: ハイパーボール)もこの検索でヒットする
   - keyword は部分一致のため、**ヒットがあっても名前が一致しているとは限らない**。各カードの名前(img の alt)を必ず確かめる。「スーパーボール」で検索すると別カード「ロケット団のスーパーボール」だけがヒットする状態を確認しており、名前を見ずに「ヒットした = 使える」と読むと誤判定する
2. 名前が一致するカードが 1 枚も無ければ `regulation_sidebar_form=all` で再検索する
   - 名前が一致するカードがヒットする → カードは実在するが、スタンダードでは使えない可能性が高い。判断に迷う場合はレギュレーションページ(下記)を確認する
   - ヒットしないまま → 検索語を短くして再試行する(部分一致を活かす)。それでもヒットしなければ、公式カード検索に存在しないカードとして扱う

README の方針の通り、公式カード検索のスタンダード絞り込みに載っていないカードはスタンダードでは使えない。

## 6. レギュレーションページの読み方

レギュレーションの現況は https://www.pokemon-card.com/rules/regulation/ で確認する。ページは次の構成(2026-08-22 確認)。

1. **使用できるカードの確認方法**: カード左下のレギュレーションマークで確認すること、マークは「サン&ムーン」シリーズ以降のカードに表示されることの説明
2. **スタンダード**: 使用できるレギュレーションマークの一覧と適用開始日、レギュレーションの説明
3. **エクストラ**、**殿堂**: それぞれの規定

読むときの注意:

- **各セクションに独立した「更新日」が付く。** 参照時はセクションの更新日を自分の確認日とあわせて記録する
- 現行の使用できるレギュレーションマークは、スタンダードセクションの「スタンダードレギュレーションで使用できるカード」の記述を読む。**この手順書にはマークの値を書かない。都度このページで確認する**
- スタンダードには「**過去のシリーズで使用できるカード**」の一覧がある。ここに載る名前のカードは古いシリーズの印刷でもデッキに入れられる。「カードの内容は、最新のカードの記述を適用します」との記載があるため、カードテキストは新しい収録の詳細ページで確認する
- 同セクションの注意書きも読むこと。「同じ効果の過去のシリーズのポケモンのカードであっても、スタンダードレギュレーションのデッキにいれることはできません」など、一覧だけでは分からない制約が書かれている

## 7. カード ID や詳細ページの URL から確認を始める場合

デッキリストの解析や参照リンクの検証などでは、カード名ではなくカード ID や詳細ページの URL が起点になる。その場合は次の順で確認する。

1. 詳細ページを開き、カード名とカードテキストを読む(手順 3〜4)
2. そのカード名で検索し、手順 5 の判定を行う

**詳細ページが `/regu/XY` 付きの URL で開けることは、スタンダードで使える根拠にならない。** スタンダードで使えないカードの詳細ページも同じ URL 形式で開ける(「スーパーボール」カード ID 046586 で確認。詳細ページは開けるが、スタンダード絞り込みの検索にこの名前のカードは出ない)。使えるかどうかの判定は、必ず検索(手順 5)で行う。

## 8. 同じ名前のカードと複数のカード ID

同じ名前のカードは、収録商品やレアリティの違いごとに別の印刷として存在し、**印刷ごとに別のカード ID が発行される**(2026-08-23 確認の例: ハイパーボールは、スタートデッキ100 バトルコレクション収録の ID 49367 と、ハイクラスパック「MEGAドリームex」収録の SR の ID 49976 が別 ID。なかよしポフィンはスタンダード絞り込みの検索だけで 16 印刷が並ぶ)。

- 検索結果に同じ名前のカードが複数並ぶのは正常。実在とスタンダード可否の判定は、印刷ではなく**名前単位**で行う(手順 5)
- 同じ名前のカードは次の 2 種類に分かれる。区別は詳細ページのカードテキストを見比べて行う
  - **印刷違い**: カード名もカードテキストも同じで、収録商品・レアリティ・イラスト・コレクションナンバーだけが違う。ルール上の違いは無く、カードテキストはどの印刷の詳細ページで読んでもよい(例: ニャオハのカード ID 50454 と 50469。2026-09-03 確認)
  - **同じ名前の別のカード**: カード名は同じだがカードテキスト(HP、ワザ、特性など)が違う。それぞれ別のカードで、対戦ではそれぞれのカードテキストに従う。ただし「同じ名前のカードは 4 枚まで」の枚数は合算して数える([基本ルール](basic-rules.md)「デッキの規定」)。古い印刷を新しい印刷の記述で読み替えてはいけない(例: ニャオハのカード ID 48781 は HP とワザが 50454 と違う別のカード。2026-09-03 確認)
- 手順 6 のレギュレーションページにある「最新のカードの記述を適用する」の扱いは、同ページの「過去のシリーズで使用できるカード」一覧に載るカードに限られる。同じ名前でカードテキストが違うポケモンには当てはまらない
- 確認記録にカード ID を残すときは、実際に採用・登録した印刷の ID を書く。カード ID がそのまま「どの印刷か」の特定になる
- **検索一覧に出ない印刷が存在する。** プロモ収録とみられる「ポケモンいれかえ」の印刷(カード ID 049602)は、スタンダード絞り込みの検索一覧(全ページ)に出ないが、詳細ページは開け、デッキ構築ツールでの登録とレギュレーションチェックは通る(2026-08-23 確認)。名前単位の使用可否は検索で判定してよいが、**特定の印刷が一覧に無いことは、その印刷が使えないことを意味しない**。印刷単位の可否はレギュレーションチェックが最終判定になる
- 印刷違いのルール上の扱いと、デッキ登録・大会での扱いは[公式デッキ構築ツールの使い方](deck-tool.md)「印刷(レアリティ・再録)違いの扱い」を参照

## 3 点確認のまとめ

| 確認したいこと | 手順 |
| --- | --- |
| 実在するか | 手順 1〜2 で検索(必要なら all で再検索)し、名前が一致するカードがあるか見る |
| スタンダードで使えるか | 手順 5 の判定に従う |
| カードテキスト | 手順 3〜4 で詳細ページを開いて読む |

確認結果を文書や会話に書くときは、詳細ページの URL と確認日を添える。
