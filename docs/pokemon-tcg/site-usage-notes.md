# 公式サイト利用上の注意

ポケモンカード公式サイト(https://www.pokemon-card.com/)を参照するすべての作業の前提となる注意事項をまとめる。[カード情報の確認手順](card-lookup.md)や[基本ルール](basic-rules.md)を使う前に読むこと。

最終確認日: 2026-08-22

## 公式サイトの利用条件

「サイトのご利用」ページ(https://www.pokemon-card.com/policy.html)に利用条件が定められている(2026-08-22 確認)。要点は次の通り。

- サイトに掲載されているすべてのコンテンツデータ(デザイン、写真、映像、文章など)の著作権または使用許諾権は株式会社ポケモンに帰属する。使用は個人的に楽しむ場合に限って許諾される
- データのコピー、複製、改変、出版、掲示、電送、配布は禁止されている。公衆ネットワーク上での利用もできない
- リンクは、サイトの著作物を複製・使用した設定が不可とされている。テキストリンクを使う
- フッターにも「掲載された画像その他の内容の無断転載はお断りします」の記載がある

robots.txt(https://www.pokemon-card.com/robots.txt)は HTTP 404 で存在しない(2026-08-22 確認)。クロール可否の機械可読な指定は無いため、後述のアクセス配慮はサーバー負荷への一般的な配慮として行う。

## このリポジトリでの振る舞い

上記の利用条件と [README の情報源の方針](../../README.md)に基づき、次のように振る舞う。

### 転載しない

- ページの本文、カード画像、スクリーンショットをリポジトリに保存しない
- カードの効果やルールに言及するときは、確認した事実を自分の言葉で書き、参照 URL と確認日を残す
- ページ本文の文言をそのまま引き写した文書を作らない

### 過度な連続アクセスをしない

アクセス頻度についての明文規定は確認できていないが、次を守る。

- 確認に必要なページだけを開く。機械的な全件取得(全カードの巡回など)をしない
- 同じ確認のために同じページを繰り返し開かない。1 回の作業で使う情報は 1 回の閲覧でまとめて読み取る
- 検索は条件を絞ってから実行し、試行錯誤で大量のリクエストを発生させない

### リンクの書き方

- 公式サイトへのリンクはテキストリンクで書く(policy.html の指定)
- ドキュメントには参照先のリンクとともに確認日を記録する

## 情報の鮮度の扱い

- レギュレーションの現況(使用できるレギュレーションマークなど)は変わっていくため、ドキュメントに固定値として書かず、都度公式レギュレーションページ(https://www.pokemon-card.com/rules/regulation/)を参照する
- このリポジトリの文書と公式サイトの記載が食い違う場合は、公式サイトを正とする
